4.6R 실습 R practice

아마존 주가에 대하여 3장 연습문제 3.10에 대하여 반응변수 High와 설명변수 Year에 대하여 단순회귀모형을 적합해 보기로 한다.

기본lm() 함수

lm() 함수를 사용하여 반응변수 High와 설명변수 Year에 대한 단순선형회귀모형을 적합할 수 있다. 기본 모형은 lm(y ~ x, data)이다. 이때 y는 반응변수, x는 설명변수를 가리킨다. 여기서 data는 두 변수가 포함된 자료를 가리킨다.

> amazon <- read.csv("amazon.csv")
> lm.fit <- lm(High ~ Year, data = amazon)
> lm.fit

Call:
lm(formula = High ~ Year, data = amazon)

Coefficients:
(Intercept)         Year
  -330.2124       0.1809

출력에서 (Intercept)가 $\hat\beta_0$, Year가 $\hat\beta_1$ 이다. 즉 적합된 회귀모형은

$$\widehat{\texttt{High}}=-330.2124+0.1809\times\texttt{Year}$$

이다.

교재는 계수 출력까지만 보여 주고 끝난다. 그런데 4장에서 배운 구간추정·가설검정·적합결여·자기상관은 모두 R 한 줄씩으로 확인할 수 있다. 아래는 4.1~4.5절의 각 내용을 R로 옮긴 것이다.

보충 — 4장의 내용을 R로 확인하기 supplement

4.2계수의 $t$ 검정 — summary() 
> summary(lm.fit)

출력의 Coefficients 표에서

  • Estimate — $\hat\beta_0,\ \hat\beta_1$
  • Std. Error — $\hat\sigma_{\hat\beta_0},\ \hat\sigma_{\hat\beta_1}$ (식 (4.5), 식 (4.12)의 제곱근)
  • t value — 식 (4.22)의 $t_0$ (단, $\beta_{10}=0$)
  • Pr(>|t|) — 그 $t_0$ 의 양측 유의확률

맨 아래 Residual standard error가 $s_{y\cdot x}=\sqrt{MSE}$, Multiple R-squared가 $r^2$, F-statistic이 분산분석의 $F_0$ 이다. 단순회귀에서는 $t_0^2=F_0$ 임을 눈으로 확인할 수 있다.

4.1신뢰구간 — confint(), predict() 
> confint(lm.fit, level = 0.95)                 # 식 (4.7), (4.12)

> nd <- data.frame(Year = 2020)
> predict(lm.fit, nd, interval = "confidence")   # 식 (4.16) — 평균반응
> predict(lm.fit, nd, interval = "prediction")   # 식 (4.19) — 개별 y

"confidence"가 $\mu_{y\cdot x}$ 의 신뢰구간, "prediction"이 개별 $y$ 값의 예측구간이다. 같은 $x$ 에서 뒤쪽이 항상 더 넓게 나오는데, 이것이 바로 식 (4.17)의 $+\sigma^2$ 이다.

4.3상관계수의 검정 — cor.test() 
> cor.test(amazon$Year, amazon$High)

출력의 t 가 식 (4.29)의 $t_0$ 이며, summary(lm.fit)의 Year 행의 t value 와 정확히 같은 값이다. 95 percent confidence interval 은 피셔의 $z$ 변환(식 (4.26))으로 구한 $\rho$ 의 신뢰구간이다.

4.4잔차의 검토와 적합결여검정 
> plot(fitted(lm.fit), resid(lm.fit))   # 그림 4.5 의 (ŷ, e) 산점도
> abline(h = 0, lty = 2)
> plot(lm.fit)                          # 진단 그림 4장 한꺼번에

# 적합결여검정 — 반복측정이 있을 때만 가능
> full  <- lm(y ~ factor(x))            # 각 수준의 평균 ȳᵢ 를 적합
> anova(lm(y ~ x), full)                # F₀ = MSLF/MSPE, 식 (4.36)

factor(x) 모형은 각 수준에서 $\bar y_i$ 를 그대로 맞추는 모형이므로 그 잔차제곱합이 곧 $SSPE$ 이고, 두 모형의 제곱합 차이가 $SSLF$ 이다. anova()의 비교 결과가 식 (4.36)의 적합결여검정과 같은 것이다.

4.5더빈–왓슨 검정 — lmtest 패키지 
> install.packages("lmtest")
> library(lmtest)
> dwtest(lm.fit, alternative = "greater")   # H₁ : ρ > 0

출력의 DW 가 식 (4.52)의 $d$ 이다. 표 A-5 의 $d_L,d_U$ 로 판정하는 대신 p-value 를 바로 주므로 불확정 구간이 생기지 않는다. 직접 계산하려면

> e <- resid(lm.fit)
> sum(diff(e)^2) / sum(e^2)

한 줄이면 된다(diff(e)가 $e_i-e_{i-1}$ 이다).
