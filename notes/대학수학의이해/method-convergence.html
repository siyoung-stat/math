수렴·발산 판정법 convergence tests

교재와 워크북의 수렴·발산 문제에서 실제로 쓰인 방법만 모았다. 이론 설명이 아니라 어떤 꼴이면 어떤 방법인지의 표다.

1. 수열의 극한 limit of a sequence

꼴을 보고 바로 고른다.

보이는 꼴방법과 예
근호끼리의 차 ($\infty-\infty$) 켤레식을 분자·분모에 곱한다. 차가 곱으로 바뀌면서 근호가 소거된다.
$\sqrt{9n^{2}+6n}-3n=\dfrac{6n}{\sqrt{9n^{2}+6n}+3n}\to 1$
$\sqrt{n^{2}+2n}-n=\dfrac{2n}{\sqrt{n^{2}+2n}+n}\to 1$
다항식 / 다항식 ($\infty/\infty$) 최고차항으로 나눈다. 남는 건 최고차 계수의 비.
$\dfrac{2n-1}{n}\to 2$,   $\dfrac{\sqrt{4n^{2}+1}}{2n}\to 1$
지수끼리 $\dfrac{a^{n}}{a^{n}+b^{n}}$ 가장 큰 밑으로 나눈다. 작은 쪽 비율이 $0$ 으로 죽는다.
$\dfrac{5^{n}}{5^{n}+4^{n}}=\dfrac{1}{1+(4/5)^{n}}\to 1$
$\sin n$, $\cos n$ 이 섞임 조임정리squeeze — 유계인 부분을 $\pm1$ 로 끼운다.
$-\dfrac1n\le\dfrac{\sin n}{n}\le\dfrac1n$ 이고 양 끝이 $0$ 이므로 $\dfrac{\sin n}{n}\to 0$
$\left(1+\dfrac{a}{n}\right)^{n}$ $e$ 꼴로 치환한다. $\dfrac{a}{n}=\dfrac1k$ 로 두면 $\left(1+\dfrac2n\right)^{n}=\left[\left(1+\dfrac1k\right)^{k}\right]^{2}=e^{2}$
극한값을 못 구하겠다 단조수렴정리 — 단조이고 유계면 수렴한다. 값은 몰라도 수렴은 보장된다. $\left(1+\frac1n\right)^{n}$ 의 수렴을 이렇게 보인다.
단조만으로도, 유계만으로도 안 된다. 둘 다 필요하다.

2. 무한급수 판정 series tests

위에서부터 차례로 걸러 내려가면 교재·워크북 문제는 전부 잡힌다.

판정법이런 꼴일 때기준과 예
① 항 판정
n-th term test		 무조건 제일 먼저.
일반항의 극한만 보면 된다.		 $a_{n}\not\to0$ 이면 즉시 발산. 계산할 것도 없다.
$\sum\dfrac{k^{2}}{k^{2}+1}$ → $a_{n}\to1\ne0$ 이라 발산
$a_{n}\to0$ 이어도 수렴은 보장되지 않는다. 다음 단계로.
② 등비급수
geometric		 $\sum ar^{k-1}$ — 항끼리의 비가 일정 $|r|<1$ 수렴, 합 $=\dfrac{a}{1-r}$.   $|r|\ge1$ 발산.
$a_{n}=\left(\dfrac35\right)^{n-1}$ → 합 $=\dfrac{1}{1-3/5}=\dfrac52$
③ $p$-급수
p-series		 $\sum\dfrac{1}{k^{p}}$ — 분모가 $k$ 의 거듭제곱 $p>1$ 수렴, $p\le1$ 발산.
$\sum\dfrac{1}{4k}$ 는 $p=1$ → 발산  ·  $\sum\dfrac{1}{k^{7/3}}$ → 수렴
쪼개서 쓰기 — $\dfrac{2k+1}{k^{4}}=\dfrac{2}{k^{3}}+\dfrac{1}{k^{4}}$, 둘 다 $p>1$ → 수렴
④ 비율판정법
ratio test		 지수 $r^{k}$, 팩토리얼처럼 이웃 항의 비가 깔끔하게 떨어지는 꼴 $c=\lim\dfrac{a_{n+1}}{a_{n}}$ 에 대해
$c<1$ 수렴  /  $c>1$ 발산  /  $c=1$ 판정 불가
$\sum\dfrac{7k^{2}}{4^{k}}$ → $c=\left(\dfrac{n+1}{n}\right)^{2}\!\cdot\dfrac14\to\dfrac14$ 수렴
$\sum\dfrac{4k}{3^{k}}$ → $c=\dfrac13$ 수렴
⑤ 비교판정법
comparison		 위 넷으로 안 되는데 부등식으로 묶을 만한 더 쉬운 급수가 보일 때 큰 게 수렴 ⟹ 작은 것도 수렴
작은 게 발산 ⟹ 큰 것도 발산
방향을 거꾸로 쓰면 안 된다.
$\dfrac{3^{k}}{5^{k}+k}\le\left(\dfrac35\right)^{k}$, 우변이 등비로 수렴 → 수렴
$\sum\dfrac{1}{k^{2}}\le1+\dfrac12+\dfrac14+\cdots=2$ → 수렴
$\sum\dfrac1k\ge1+\dfrac12+\dfrac12+\cdots$ → 발산
⑥ 교대급수 판정
alternating		 $\sum(-1)^{k-1}a_{k}$ — 부호가 번갈아 바뀜 $a_{n}$ 이 단조감소하고 $a_{n}\to0$ 이면 수렴. (두 조건 모두 필요)
$1-\dfrac{1}{2^{2}}+\dfrac{1}{3^{2}}-\cdots$ → $\dfrac{1}{n^{2}}$ 이 단조감소·$\to0$ 이라 수렴
⑦ 절대수렴 / 조건수렴
absolute · conditional		 교대급수가 수렴한 뒤, 어느 쪽 수렴인지 물을 때 절댓값 급수 $\sum|a_{k}|$ 를 따로 판정한다.
$\sum|a_{k}|$ 수렴 → 절대수렴(원급수도 자동 수렴)
$\sum|a_{k}|$ 발산인데 $\sum a_{k}$ 수렴 → 조건수렴
$\sum\dfrac{(-1)^{k}}{\sqrt k}$ → 교대급수로 수렴, $\sum\dfrac{1}{\sqrt k}$ 는 $p=\dfrac12$ 라 발산 → 조건수렴
$\sum\dfrac{(-1)^{k}}{k^{p}}$ 의 절대수렴 조건 $=\sum\dfrac{1}{k^{p}}$ 의 수렴 조건 $=\mathbf{p>1}$
가장 많이 틀리는 곳 — $a_{n}\to0$ 은 수렴의 필요조건일 뿐이다. 조화급수 $\sum\dfrac1k$ 이 반례다. 일반항은 $0$ 으로 가는데 급수는 발산한다.
즉 ①로는 발산만 결론낼 수 있고, 수렴은 결론낼 수 없다.

3. 특이적분 improper integral

끝점을 극한으로 바꿔 계산한다. 값이 유한하면 수렴, $\pm\infty$ 면 발산. 판정법이 따로 없고 그냥 계산이다.

적분계산
$\displaystyle\int_{1}^{\infty}\frac{1}{x^{2}}dx$ $\lim\limits_{t\to\infty}\left[-\frac1x\right]_{1}^{t}=1$   수렴
$\displaystyle\int_{1}^{\infty}\frac{\ln x}{x^{2}}dx$ 부분적분 → $1$   수렴
$\displaystyle\int_{e}^{\infty}\frac{1}{x\ln x}dx$ $[\ln(\ln x)]_{e}^{t}\to\infty$   발산 — 분모가 커 보여도 발산한다
$\displaystyle\int_{0}^{\infty}xe^{-2x}dx$ 부분적분 → $\dfrac14$   수렴
$\displaystyle\int_{0}^{1}\ln x\,dx$ $\lim\limits_{t\to0^{+}}[x\ln x-x]_{t}^{1}=-1$   수렴
($x\ln x\to0$ 은 로피탈로 먼저 확인)

4. 진폭 · 주기 · 위상각 amplitude, period, phase

기준 꼴로 맞춰 놓고 읽으면 된다.

$$y=A\cos(\omega x-\varphi)+d \qquad\text{또는}\qquad y=A\sin(\omega x-\varphi)+d$$
이름값과 뜻
진폭 amplitude $|A|$ — 중심선에서 위아래로 흔들리는 폭. $\dfrac{\text{최댓값}-\text{최솟값}}{2}$ 와 같다.
주기 period $\dfrac{2\pi}{|\omega|}$ — 그래프가 한 번 반복되는 데 걸리는 $x$ 의 길이. $\omega$ 가 클수록 촘촘하다.
$\tan$ 은 $\dfrac{\pi}{|\omega|}$ 로 다르다.
위상각 phase $\varphi$ — 괄호 안의 상수항 그 자체. 그래프를 오른쪽으로 $\dfrac{\varphi}{\omega}$ 만큼 민 것과 같다($=$ 위상이동).
위상각과 위상이동은 다르다. $\cos\!\left(3x-\frac{\pi}{4}\right)$ 에서 위상각은 $\frac{\pi}{4}$ 지만, 실제로 그래프가 밀린 거리는 $3$ 으로 나눈 $\frac{\pi}{12}$ 다. 문제가 묻는 게 어느 쪽인지 보고 답할 것.
식진폭 / 주기 / 위상각
$y=\cos\!\left(3x-\dfrac{\pi}{4}\right)$ $1$  /  $\dfrac{2\pi}{3}$  /  $\dfrac{\pi}{4}$
$y=3\sin(2x)$ $3$  /  $\pi$  /  $0$
$y=2\cos\!\left(x-\dfrac{\pi}{3}\right)$ $2$  /  $2\pi$  /  $\dfrac{\pi}{3}$
$y=-2\tan x$ 진폭 없음(무한히 커진다)  /  $\pi$  /  $0$
