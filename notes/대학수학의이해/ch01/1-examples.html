1.3다음 집합 중 원소나열법으로 나타내기 어려운 것을 고르시오.
  1. $A=\{x\mid -1\lt x\lt 4,\ x \text{ 는 정수}\}$
  2. $B=\{x\mid x \text{ 는 } 2 \text{ 의 배수인 자연수}\}$
  3. $C=\{x\mid -1\le x\le 4,\ x \text{ 는 실수}\}$
  4. $D=\{x\mid x \text{ 는 } 12 \text{ 의 약수}\}$
1.4다음 집합 $A,B,C$ 의 포함 관계에 대한 참과 거짓을 밝히시오.

  3. $A\subset B$, $B\subset C$, $C\subset A$ 이면 $A=B=C$ 이다.
  4. $A\subset B$, $B\subset C$ 이면 $A\subset C$ 이다.
1.5집합 $A=\{1,2\}$ 의 부분집합을 모두 구하시오.
1.6집합 $U=\{x\mid x \text{ 는 정수}\}$ 를 전체집합이라고 할 때, 다음 중 공집합인 것을 모두 고르시오.
  1. $A=\{x\mid x=-x\}$
  2. $B=\{x\mid x=-|x|\}$
  3. $C=\{x\mid x^{2}\lt0\}$
  4. $D=\left\{x\ \middle|\ \dfrac32x-4=0\right\}$
1.7전체집합 $U=\{x\mid x \text{ 는 실수}\}$ 일 때, $N=\{x\mid x \text{ 는 자연수}\}$, $Z=\{x\mid x \text{ 는 정수}\}$, $Q=\{x\mid x \text{ 는 유리수}\}$ 의 포함 관계를 벤다이어그램으로 나타내시오.

1.11다음 각각의 경우 $A-B$ 를 구하시오.

1.1 집합
1.1정답 $(4)$

집합은 구성 요소가 객관적 기준에 따라 명확히 정의된 것이어야 한다. ‘부자’, ‘키 큰’, ‘맛있는’, ‘건강한’은 사람마다 기준이 달라 포함 여부를 판정할 수 없다. $12$ 의 약수는 $1,2,3,4,6,12$ 로 누가 보아도 같게 정해진다.

1.2정답
  1. $A=\{x\mid x \text{ 는 짝수}\}$ 또는 $A=\{x\mid x=2n,\ n \text{ 은 자연수}\}$
  2. $B=\{x\mid 2\le x\le 13,\ x \text{ 는 소수}\}$
1.3정답 $(3)$

$(1)\ A=\{0,1,2,3\}$,  $(2)\ B=\{2,4,6,\dots\}$,  $(4)\ D=\{1,2,3,4,6,12\}$ 로 나열된다. $(2)$ 는 무한하지만 규칙이 있어 $\dots$ 로 이어 쓸 수 있는 반면, $(3)$ 의 실수는 이어 쓸 ‘다음 원소’가 없어 나열이 불가능하다.

1.4정답 $(1)$ 거짓,  $(2)$ 참,  $(3)$ 참,  $(4)$ 참
  1. 방향이 반대다. $-1\in B$ 이지만 $-1\notin A$ 이므로 $A\subset B$ 이다.
  2. $B=\{x\mid x\gt1 \text{ 또는 } x\lt-1\}$ 이므로 $A\subset B$ 이고, $-2\in B$, $-2\notin A$ 이므로 $A\ne B$ — 진부분집합이다.
  3. $B\subset C\subset A$ 에서 $B\subset A$ 이므로 $A=B$ 이고, 같은 방식으로 $B=C$.
  4. $x\in A\Rightarrow x\in B\Rightarrow x\in C$ (포함 관계의 추이성).
1.5정답 $\phi,\ \{1\},\ \{2\},\ \{1,2\}$ 의 $4$ 개

각 원소를 넣거나 빼는 두 가지 선택이 있으므로 $2^{2}=4$ 개다.

1.6정답 $(3)$ 과 $(4)$
  1. $x=-x\Rightarrow 2x=0\Rightarrow x=0$ 이므로 $A=\{0\}$ — 공집합이 아니다.
  2. $x=-|x|$ 는 $x\le0$ 을 뜻하므로 $B=\{x\mid x \text{ 는 } 0 \text{ 이거나 음의 정수}\}$.
  3. 실수의 제곱은 음이 될 수 없으므로 $C=\phi$.
  4. $\tfrac32x=4$ 에서 $x=\tfrac83$ 인데 정수가 아니므로 $U$ 안에 해가 없어 $D=\phi$.

$(4)$ 는 전체집합을 실수로 잡았다면 $D=\left\{\tfrac83\right\}$ 이 되어 공집합이 아니다.

1.7정답 $N\subset Z\subset Q\subset U$

가장 안쪽에 $N$, 그것을 감싸는 $Z$, 다시 그것을 감싸는 $Q$ 를 그리고, 바깥 직사각형이 $U$ 다. $U$ 에서 $Q$ 를 뺀 나머지 부분이 무리수에 해당한다.

1.2 집합의 연산
1.8정답
  1. $A\cup B=\{x\mid x \text{ 는 실수}\}$ — 유리수와 무리수를 합치면 실수 전체.
  2. $6$ 의 배수는 모두 $3$ 의 배수이므로 $B\subset A$, 따라서 $A\cup B=A$.
  3. $A\cup B=\{x\mid -3\le x\le2 \text{ 인 실수}\}$ — 왼쪽 끝은 $B$, 오른쪽 끝은 $A$ 가 결정한다.
1.9정답
  1. $A\cap B=\phi$ — 유리수이면서 무리수인 수는 없다(서로소).
  2. $B\subset A$ 이므로 $A\cap B=B=\{x\mid x \text{ 는 자연수}\}$.
  3. $A\cap B=\{x\mid -1\le x\lt1 \text{ 인 실수}\}$ — 왼쪽 끝은 $A$, 오른쪽 끝은 $B$ 가 결정한다.
1.10정답
  1. $A^{C}=\{4,5\}$
  2. $A^{C}=\{x\mid x \text{ 는 무리수}\}$

여집합은 전체집합을 무엇으로 잡았는가에 따라 완전히 달라진다.

1.11정답
  1. $A-B=\{1,3,5,6\}$ — $B$ 에만 있는 $7,9$ 는 $A$ 에 없으므로 영향이 없다.
  2. $A-B=\{x\mid x \text{ 는 자연수}\}$
  3. $A-B=\{x\mid x \text{ 는 무리수}\}$ — $A=U$ 이므로 $A-B=B^{C}$ 와 같다.
1.3 집합에 관한 정리
1.12정답 두 집합 모두 $\{a,b,c,e\}$ 로 같다(분배법칙).
  1. $B\cap C=\{e\}$ 이므로 $A\cup(B\cap C)=\{a,b,c\}\cup\{e\}=\{a,b,c,e\}$
  2. $A\cup B=\{a,b,c,d,e\}$, $A\cup C=\{a,b,c,e,f\}$ 이므로 교집합은 $\{a,b,c,e\}$
1.13정답 $(1)\ U$  $(2)\ A\cap B$  $(3)\ A\cup B$

$(1)$ 결합법칙으로 묶는 순서를 바꾼 뒤 $A\cup A^{C}=U$ 를 쓴다.

$$A\cup(A^{C}\cup B)=(A\cup A^{C})\cup B=U\cup B=U$$

$(2)$ 분배법칙을 쓴 뒤 $A\cap A^{C}=\phi$ 를 쓴다.

$$A\cap(A^{C}\cup B)=(A\cap A^{C})\cup(A\cap B)=\phi\cup(A\cap B)=A\cap B$$

$(3)$ 앞의 두 항을 먼저 묶는 것이 요령이다.

$$\begin{aligned} (A\cap B)\cup(A\cap B^{C})\cup(A^{C}\cap B) &=\left[A\cap(B\cup B^{C})\right]\cup(A^{C}\cap B)\\ &=A\cup(A^{C}\cap B)=(A\cup A^{C})\cap(A\cup B)\\ &=U\cap(A\cup B)=A\cup B \end{aligned}$$
1.14정답 차집합을 $A-B=A\cap B^{C}$ 로 바꾸고 분배법칙과 드모르간의 법칙을 쓴다. $$\begin{aligned} (A-B)\cup(A-C)&=(A\cap B^{C})\cup(A\cap C^{C})\\ &=A\cap(B^{C}\cup C^{C}) &&\text{(분배법칙)}\\ &=A\cap(B\cap C)^{C} &&\text{(드모르간의 법칙)}\\ &=A-(B\cap C) \end{aligned}$$
1.4 원소의 개수 · 곱집합 · 확률
1.15정답 $13$ 개

$A=\{2,4,\dots,20\}$, $B=\{3,6,\dots,18\}$ 이고 $A\cap B$ 는 $6$ 의 배수 $\{6,12,18\}$ 이므로

$$n(A\cup B)=n(A)+n(B)-n(A\cap B)=10+6-3=13$$
1.16정답 $(1)\ pq$  $(2)\ p(p-1)$

$(2)$ 는 $A\times A$ 의 원소 $p^{2}$ 개에서 두 성분이 같은 $(x,x)$ 꼴 $p$ 개를 빼면 되므로 $p^{2}-p=p(p-1)$ 이다.

1.17정답 $(1)\ \dfrac12$  $(2)\ \dfrac12$

$(1)$ 표본공간이 $\{1,2,3,4,5,6\}$ 이고 짝수가 나오는 사건은 $\{2,4,6\}$ 이므로 $P(A)=\tfrac36=\tfrac12$.

$(2)$ 표본공간은 $\{(H,H),(H,T),(T,H),(T,T)\}$ 이고 사건은 $\{(H,T),(T,H)\}$ 이므로 $P(B)=\tfrac24=\tfrac12$. $(H,T)$ 와 $(T,H)$ 를 하나로 묶어 세면 $\tfrac13$ 으로 틀린다.

1.5 수의 체계
1.18정답 $$|a+1|+|a-2|=\begin{cases}2a-1 & (a\ge2)\\ 3 & (-1\le a\lt2)\\ -2a+1 & (a\lt-1)\end{cases}$$

부호가 바뀌는 지점 $a=-1,\ a=2$ 로 실수를 세 구간으로 나눈다.

  1. $a\ge2$: $(a+1)+(a-2)=2a-1$
  2. $-1\le a\lt2$: $(a+1)-(a-2)=3$
  3. $a\lt-1$: $-(a+1)-(a-2)=-2a+1$

가운데 구간에서 답이 상수 $3$ 인 것은 $a$ 가 $-1$ 과 $2$ 사이에 있으면 두 거리의 합이 두 점 사이의 거리 $3$ 과 같기 때문이다.

1.7 증명법
1.20정답 성립한다(직접증명).

$n$ 이 짝수이므로 $n=2k$ ($k$ 는 정수)로 쓰면

$$n^{2}=(2k)^{2}=4k^{2}=2\cdot(2k^{2})$$

$2k^{2}$ 이 정수이므로 $n^{2}$ 은 짝수이다.

1.21정답 귀류법.
  1. 부정을 가정. $\sqrt2$ 가 유리수라고 가정하면 $\sqrt2=\dfrac{a}{b}$ ($a,b$ 는 서로소인 정수, $b\ne0$)로 쓸 수 있다.
  2. 제곱. $2=\dfrac{a^{2}}{b^{2}}$ 에서 $2b^{2}=a^{2}$.
  3. $a$ 가 짝수. $a^{2}$ 이 짝수이므로 $a$ 도 짝수이고 $a=2k$.
  4. $b$ 도 짝수. 대입하면 $2b^{2}=4k^{2}$, 즉 $b^{2}=2k^{2}$ 이므로 $b$ 도 짝수.
  5. 모순. $a,b$ 가 모두 짝수여서 서로소 가정에 모순이다. 따라서 $\sqrt2$ 는 무리수다.

1.22정답 수학적 귀납법.

기초 단계. $n=1$ 일 때 $1=\dfrac{1\cdot2}{2}=1$ 로 성립한다.

귀납 단계. $n=k$ 에서 $1+2+\cdots+k=\dfrac{k(k+1)}{2}$ 라고 가정하고 양변에 $k+1$ 을 더하면

$$1+\cdots+k+(k+1)=\frac{k(k+1)}{2}+(k+1)=\frac{k(k+1)+2(k+1)}{2}=\frac{(k+1)(k+2)}{2}$$

이는 $n=k+1$ 일 때의 식 $\dfrac{(k+1)\{(k+1)+1\}}{2}$ 와 같다. 따라서 모든 자연수 $n$ 에 대하여 등식이 성립한다.
