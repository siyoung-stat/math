A. 합과 평균의 분포 (3.2)

Q1$X_1,\dots,X_5\overset{\text{iid}}{\sim}\text{EXP}(2)$ ($\theta=2$ 는 scale) 일 때 다음을 구하여라.예제 3.3
  1. $T=\sum_i X_i$ 의 분포
  2. $\bar X$ 의 분포
Q2★독립인 연속형 $X,Y$ 에 대해 $W=X+Y$ 의 PDF 를 구하는 합성곱 공식을 식으로 쓰라.

B. 정규표본의 정확분포 (3.3)

Q3정규표본의 핵심 정리: $X_1,\dots,X_n\overset{\text{iid}}{\sim}N(\mu,\sigma^2)$, $n\ge2$ 일 때
  1. $\bar X$ 의 분포를 쓰라.
  2. $(n-1)S^2/\sigma^2$ 의 분포를 쓰라.
  3. ★$\bar X$ 와 $S^2$ 의 관계를 쓰라.
  4. $t$ 분포를 따르는 통계량 $T$ 를 식으로 쓰고, 그 분포(자유도 포함)를 쓰라.

C. 수렴, 중심극한정리, Slutsky, Delta 방법 (3.4)

Q4확률변수열 $T_n$ 의 수렴에 대하여
  1. ★확률수렴 $T_n\xrightarrow{p}T$ 의 정의를 식으로 쓰라.
  2. ★분포수렴 $T_n\xrightarrow{d}T$ 의 정의를 식으로 쓰라.
Q5중심극한정리에 대하여
  1. 정리를 식으로 쓰라(조건 포함).
  2. ★mgf 가 $0$ 의 열린 근방에서 존재할 때 정리를 증명하라.
Q6$T\sim\text{Bin}(100,0.4)$ 일 때 $P(35\le T\le45)$ 를 연속성 수정을 써서 정규근사하라.예제 3.8
Q7★다음 정리를 식으로 설명하라.
  1. 연속사상 정리
  2. Slutsky 정리
Q8★일차 Delta 방법을 식으로 쓰라(조건 포함).
Q9★$X_i\overset{\text{iid}}{\sim}\text{EXP}(\theta)$ ($\theta$ 는 scale) 일 때 $1/\theta$ 의 추정량 $1/\bar X$ 에 대하여예제 3.9
  1. $1/\bar X$ 의 일치성을 보여라.
  2. $\sqrt n\big(\tfrac1{\bar X}-\tfrac1\theta\big)$ 의 점근분포를 구하여라.

D. 순서통계량 (3.5)

Q10독립·동일분포, 절대연속인 모집단(CDF $F$, PDF $f$)의 순서통계량에 대하여
  1. ★$X_{(r)}$ 의 CDF 를 식으로 쓰라.
  2. ★$X_{(r)}$ 의 PDF 를 식으로 쓰라.
  3. 최댓값 $X_{(n)}$ 의 CDF 를 쓰라.
  4. 최솟값 $X_{(1)}$ 의 CDF 를 쓰라.
Q11$X_1,\dots,X_n$ 이 공통 CDF $F$, PDF $f$ 를 갖는 연속형 확률표본이고, 이를 작은 순서로 나열한 순서통계량을 $X_{(1)}\lt X_{(2)}\lt\cdots\lt X_{(n)}$ 이라 하자.
  1. ★$n$ 개 순서통계량 전체 $(X_{(1)},\dots,X_{(n)})$ 의 결합 PDF 를 받침과 함께 쓰라.
  2. $1\le r\lt s\le n$ 일 때 두 순서통계량 $(X_{(r)},X_{(s)})$ 의 결합 PDF 를 받침과 함께 쓰라.
  3. ★최솟값과 최댓값 $(X_{(1)},X_{(n)})$ 의 결합 PDF 를 받침과 함께 쓰라.
  4. 모집단이 $U(0,1)$ 일 때 $r$ 번째 순서통계량 $X_{(r)}$ 이 따르는 분포의 이름과 모수를 쓰라.
  5. (4) 에서 $E(X_{(r)})$ 를 $r,n$ 으로 쓰라.
  6. ★(4) 에서 $Var(X_{(r)})$ 를 $r,n$ 으로 쓰라.
  7. $Y\sim\text{Beta}(\alpha,\beta)$ 일 때 $E(Y)$ 를 쓰라.
  8. ★$Y\sim\text{Beta}(\alpha,\beta)$ 일 때 $Var(Y)$ 를 쓰라.
Q12$X_i\overset{\text{iid}}{\sim}U(0,\theta)$, $\theta\gt0$, $M=X_{(n)}$ 일 때 다음을 구하여라.예제 3.10
  1. $M$ 의 CDF
  2. $M$ 의 PDF
  3. $E(M^k)\ (k\gt0)$
  4. $E(M)$
  5. $Var(M)$
  6. $M$ 으로 만든 $\theta$ 의 불편추정량
  7. 그 불편추정량의 분산
Q13$X_1,\dots,X_5\overset{\text{iid}}{\sim}U(0,1)$ 일 때 표본중앙값 $X_{(3)}$ 에 대하여 다음을 구하여라.예제 3.11
  1. ★$X_{(3)}$ 의 PDF
  2. $X_{(3)}$ 이 따르는 분포의 이름과 모수
  3. ★$P(X_{(3)}\le0.4)$
Q14$X_i\overset{\text{iid}}{\sim}U(0,1)$, $n\ge2$ 일 때 범위 $R=X_{(n)}-X_{(1)}$ 에 대하여 다음을 구하여라.예제 3.12
  1. ★$U=X_{(1)},\ V=X_{(n)}$ 의 결합 PDF
  2. ★$R$ 의 PDF
  3. $R$ 이 따르는 분포
  4. $E(R)$
