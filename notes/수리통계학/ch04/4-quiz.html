■ 문제 시트 questions

A. 적률추정법과 최대가능도 추정법 (4.1–4.2)

Q1$X_i\overset{\text{iid}}{\sim}U(0,\theta)$ 일 때 다음을 구하여라.예제 4.1
  1. $\theta$ 의 적률추정량
  2. 자료가 $1,2,3,8$ 일 때 (1) 의 추정값
  3. (2) 의 추정값이 자료와 모순되는 점
Q2$X_i\overset{\text{iid}}{\sim}\text{GAM}(k,\theta)$ (pdf $f(x)=\frac1{\Gamma(k)\theta^k}x^{k-1}e^{-x/\theta}$) 에서 $k,\theta$ 가 모두 미지일 때 다음을 구하여라.예제 4.2
  1. $k,\theta$ 의 적률추정량 ($v_n=\frac1n\sum(X_i-\bar X)^2$ 을 써서)
  2. $\bar x=6$, $m_2'=45$ 일 때 $k,\theta$ 의 추정값
Q3$X_i\overset{\text{iid}}{\sim}N(\mu,\sigma^2)$ 에서 두 모수가 모두 미지일 때 다음을 구하여라.예제 4.4
  1. $\mu$ 의 MLE
  2. $\sigma^2$ 의 MLE
  3. $\sigma^2$ 의 MLE 의 편향
Q4$X_i\overset{\text{iid}}{\sim}U(0,\theta)$, $\theta\gt0$ 일 때 다음을 구하여라.예제 4.5
  1. 지시함수를 포함한 가능도함수 $L(\theta)$
  2. $\theta$ 의 MLE
Q5$X_i\overset{\text{iid}}{\sim}\text{EXP}(\theta)$ (pdf $f(x)=\tfrac1\theta e^{-x/\theta}$) 일 때
  1. $\theta$ 의 MLE 를 구하고, 정지점이 최대임을 확인하라.
  2. $1/\theta$ 의 MLE 를 구하여라.
  3. (2) 의 MLE 가 $1/\theta$ 의 불편추정량인지 판단하라.

B. 추정의 기준 (4.3)

Q6$\tau(\theta)$ 의 추정량 $T$ 에 대하여
  1. 편향의 정의를 식으로 쓰라.
  2. 평균제곱오차를 분산과 편향으로 분해하는 식을 쓰고 증명하라.
Q7정규표본에서 $\sigma^2$ 의 두 추정량 $S^2$ 와 $V_n=\frac{n-1}nS^2$ 에 대하여 다음을 구하여라.예제 4.6
  1. $MSE(S^2)$
  2. $MSE(V_n)$
  3. 두 MSE 중 작은 쪽
Q8$U(0,\theta)$ 표본에서 $T_1=2\bar X$, $T_2=\frac{n+1}nX_{(n)}$ 일 때 다음을 구하여라.예제 4.7
  1. $Var(T_1)$
  2. $Var(T_2)$
  3. $n\gt1$ 에서 분산이 작은 쪽
Q9한 관측값의 Fisher 정보에 대하여 (정규조건 가정)
  1. 점수함수 $U_1(\theta)$ 를 식으로 쓰라.
  2. $E_\theta[U_1(\theta)]$ 의 값을 쓰고 증명하라.
  3. $I_1(\theta)$ 를 두 가지 식으로 쓰라.
  4. iid 표본의 정보 $I_n(\theta)$ 를 $I_1(\theta)$ 로 쓰라.
Q10Cramér–Rao 분산하한에 대하여
  1. $\tau(\theta)$ 의 불편추정량 $T$ 에 대한 정리를 식으로 쓰라.
  2. 정리를 증명하라.
Q11$X_i\overset{\text{iid}}{\sim}\text{Bernoulli}(p)$, $p\in(0,1)$ 일 때 다음을 구하여라.예제 4.8
  1. $U_1(p)$
  2. $I_1(p)$
  3. $p$ 의 불편추정량의 분산하한
  4. $\bar X$ 가 하한을 달성하는지 여부

  2. Fisher–Neyman 인수분해 정리를 식으로 쓰라.

Q13완비통계량에 대하여
  1. 완비성의 정의를 식으로 쓰라.
  2. $T\sim\text{Bin}(n,p)$, $p\in(0,1)$ 이 완비임을 증명하라.
Q14Rao–Blackwell 정리에 대하여
  1. 정리를 식으로 쓰라.
  2. 정리를 증명하라.
Q15Lehmann–Scheffé 정리에 대하여
  1. 정리를 쓰라.
  2. 정리를 증명하라.
Q16$X_i\overset{\text{iid}}{\sim}\text{Bernoulli}(p)$, $n\ge2$, $T=\sum_iX_i$ 일 때 다음을 구하여라.예제 4.10
  1. $X_1,X_2$ 로 만든 $p^2$ 의 간단한 불편추정량
  2. $E(X_1X_2\mid T=t)$
  3. $p^2$ 의 UMVUE
  4. $E(\bar X^2)$
Q17$X_i\overset{\text{iid}}{\sim}\text{Poisson}(\lambda)$, $n\ge2$, $T=\sum_iX_i$ 일 때 다음을 구하여라.예제 4.11
  1. $X_1$ 로 만든 $e^{-\lambda}$ 의 간단한 불편추정량
  2. $X_1\mid T=t$ 의 분포
  3. $e^{-\lambda}$ 의 UMVUE
Q18$X_i\overset{\text{iid}}{\sim}U(0,\theta)$, $M=X_{(n)}$ 에 대하여예제 4.12
  1. $M$ 이 완비임을 증명하라.
  2. $\theta$ 의 UMVUE 를 구하여라.

D. 추정량의 점근적 성질 (4.5)

Q19일치추정량에 대하여
  1. 일치추정량의 정의를 식으로 쓰라.
  2. $MSE_\theta(T_n)\to0$ 이면 $T_n$ 이 일치추정량임을 증명하라.
Q20정규적인 모형의 MLE 에 대하여
  1. $\sqrt n(\hat\theta-\theta_0)$ 의 점근분포를 쓰라.
  2. (1) 을 증명하라.
Q21$X_i\overset{\text{iid}}{\sim}\text{EXP}(\theta)$ (pdf $f(x)=\tfrac1\theta e^{-x/\theta}$), $T=\sum_iX_i$ 이고 $1/\theta$ 의 추정량을 $\hat\lambda=n/T$ 라 할 때 다음을 구하여라.예제 4.14
  1. $E(T^{-k})$ $(n\gt k)$
  2. $\hat\lambda$ 의 편향
  3. $1/\theta$ 의 불편추정량 $\tilde\lambda$
  4. $Var(\tilde\lambda)$ $(n\gt2)$
  5. $\sqrt n\big(\hat\lambda-\tfrac1\theta\big)$ 의 점근분포
Q22$M_n$ 이 $U(0,\theta)$ 표본의 최댓값일 때 $n(\theta-M_n)/\theta$ 의 극한분포를 구하여라.예제 4.15

E. 구간추정 (4.6)

Q23$X_i\overset{\text{iid}}{\sim}N(\mu,\sigma^2)$, $n\ge2$ 일 때 정확한 $1-\alpha$ 신뢰구간을 쓰라.
  1. $\mu$ ($\sigma$ 기지)
  2. $\mu$ ($\sigma$ 미지)
  3. $\sigma^2$ ($\mu$ 미지)
  4. $\sigma^2$ ($\mu$ 기지)
Q24다음 정규표본의 95% 신뢰구간을 구하여라.예제 4.16·4.17
  1. $n=25$, $\bar x=10$, $s=2$ 일 때 $\mu$ ($t_{24,0.975}=2.0639$)
  2. $n=16$, $s^2=9$ 일 때 $\sigma^2$ ($\chi^2_{15,0.025}=6.2621$, $\chi^2_{15,0.975}=27.4884$)
Q25$X_i\overset{\text{iid}}{\sim}\text{EXP}(\theta)$ (pdf $f(x)=\tfrac1\theta e^{-x/\theta}$), $T=\sum_iX_i$ 일 때예제 4.18
  1. 추축량 $2T/\theta$ 의 분포를 쓰라.
  2. $\theta$ 의 정확한 $1-\alpha$ 신뢰구간을 쓰라.
  3. $n=10$, $\sum x_i=20$ 일 때 $\theta$ 의 MLE 를 구하여라.
  4. (3) 에서 $\theta$ 의 95% 정확 신뢰구간을 구하여라. ($\chi^2_{20,0.025}=9.5908$, $\chi^2_{20,0.975}=34.1696$)
Q26$X_i\overset{\text{iid}}{\sim}U(0,\theta)$, $M=X_{(n)}$ 일 때
  1. $M/\theta$ 의 분포를 쓰라.
  2. $\theta$ 의 정확한 $1-\alpha$ 신뢰구간을 유도하라.
Q27점근 신뢰구간을 식으로 쓰라.
  1. 정규적인 MLE $\hat\theta$ 의 Wald 구간
  2. Bernoulli 모비율 $p$ 의 Wald 구간
  3. Bernoulli 모비율 $p$ 의 Wilson 구간
