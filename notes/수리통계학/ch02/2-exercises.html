2장 본문의 예제와 교재 연습문제를 모은 것이다. 정답 시트는 인쇄 시 다음 페이지부터 나온다. 자세한 유도는 본문 노트와 증명·정리 퀴즈 참고.

가우스적분 Gaussian integral

$a\gt0$ 일 때 다음 두 공식을 쓴다. 정규분포의 밀도·적률생성함수가 모두 여기서 나온다. $$\int_{-\infty}^{\infty}e^{-ax^2}dx=\sqrt{\frac\pi a},\qquad \int_{-\infty}^{\infty}e^{-ax^2+bx}dx=\sqrt{\frac\pi a}\;e^{\frac{b^2}{4a}}$$

G1다음 적분의 값을 구하라. $$\int_{-\infty}^{\infty}e^{-4x^2}dx$$
G2다음 적분의 값을 구하라. $$\int_{-\infty}^{\infty}e^{-3x^2+6x}dx$$
G3다음 적분의 값을 구하라. $$\int_{-\infty}^{\infty}e^{-\frac{x^2}{2}+2x}dx$$

연습문제 exercises

04$n$ 개의 함수 $f_i(x)\ (i=1,2,\cdots,n)$ 들이 각각 확률밀도함수의 조건들을 만족하면, $p_i\gt0$, $\displaystyle\sum_{i=1}^n p_i=1$ 에 대하여 $\displaystyle\sum_{i=1}^n p_if_i$ 도 확률밀도함수의 조건들을 만족함을 보여라.
06확률변수 $X$ 의 누적분포함수가 $$F_X(x)=\begin{cases}0,& x\lt0\\ 1-(1/2)^{x+1},& x=0,1,2,\cdots\end{cases}$$ 으로 주어졌다. 이때
  1. 확률변수 $X$ 의 확률밀도함수를 구하라.
  2. $X$ 가 짝수값을 가질 확률을 구하라.
  3. $P(10\lt X\lt20)$ 을 구하라.
08이변량 확률벡터 $(X,Y)$ 의 결합 누적분포함수가 $F(x,y)$ 라고 할 때 $$P(a\lt X\le b,\ c\lt Y\le d)=F(b,d)-F(b,c)-F(a,d)+F(a,c)$$ 이 성립함을 보여라.
12두 확률변수 $X$ 와 $Y$ 의 결합 확률밀도함수가 $$f_{X,Y}(x,y)=\begin{cases}2e^{-x}e^{-2y},& 0\lt x\lt\infty,\ 0\lt y\lt\infty\\ 0,& \text{그 외의 경우}\end{cases}$$ 라고 하자. 이때
  1. $P(X\gt1,\ Y\lt1)$ 을 구하라.
  2. $P(X\lt Y)$ 를 구하라.
  3. 양의 상수 $a$ 에 대하여 $P(X\gt a)$ 을 구하라.
16두 확률변수 $X,Y$ 의 결합 확률밀도함수가 $$f_{X,Y}(x,y)=2,\qquad 0\lt x\lt1,\ 0\lt y\lt1-x$$ 일 때,
  1. 조건부 확률밀도함수 $f_{Y\mid x}(y\mid x)$ 를 구하라.
  2. $P(0\lt Y\lt3/4\mid X\lt1/2)$ 을 구하라.
18확률변수 $X$ 의 확률밀도함수가 $f_X(x)=1,\ 0\lt x\lt1$ 일 때, $Y=3X+1$ 의 확률밀도함수를 구하라.
20확률변수 $X$ 의 확률밀도함수가 $f_X(x)=3e^{-3x},\ x\gt0$ 일 때
  1. $Y=2X+5$ 의 확률밀도함수와 확률분포함수를 구하라.
  2. $Y=\dfrac1X$ 의 확률밀도함수와 확률분포함수를 구하라.
22$X\sim N(0,1)$ 일 때, $Y=X^2$ 의 확률밀도함수를 누적분포함수를 이용한 방법으로 구하라.
23연속형 확률변수 $X$ 의 누적분포함수를 $F(x)$ 라고 하면, $U=F(X)$ 는 구간 $(0,1)$ 상에서 균일분포를 가짐을 보여라.
24두 확률변수 $X,Y$ 의 결합 확률밀도함수가 $$f_{X,Y}(x,y)=2(x+y),\qquad 0\le x\le y\le1$$ 일 때, $Z=X+Y$ 의 확률밀도함수를 구하라.
27이산형 확률변수 $X$ 의 확률밀도가 $$f(x)=\begin{cases}2^{-x},& x=1,2,\cdots\\ 0,& \text{그 외의 경우}\end{cases}$$ 으로 주어졌을 때, $2^X$ 의 기댓값이 존재하지 않음을 보여라 (참조: 정의 2.7).
29$Var(X)=0$ 의 필요충분조건은 $X=$상수임을 보여라.
34$F_{X,Y}(x,y)=F_X(x)F_Y(y)$ 가 두 확률변수 $X$ 와 $Y$ 가 서로 독립일 필요충분조건이 됨을 보여라.
35확률변수 $U$ 가 $[0,2\pi]$ 상에서 균일분포를 따른다고 할 때 $X=\cos U,\ Y=\sin U$ 라는 변환을 고려하자. 그러면 $X$ 와 $Y$ 는 서로 독립이 아님을 보여라.
36확률변수 $X$ 의 확률밀도함수가 $f_X(-1)=f_X(0)=f_X(1)=1/3$ 로 주어졌을 때 $Y=2|X|$ 라고 하자. 이때
  1. $Y=2|X|$ 와 $X$ 는 서로 독립이 아님을 보여라.
  2. $E(XY)=E(X)E(Y)$ 임을 보여라.
37두 친구 A와 B가 어떤 특정한 장소에서 오후 6시에 만나기로 하였다. 이 두 사람이 이 장소에 도착하는 시간은 5시 50분에서 6시 10분 사이에 균일하게 분포하며 서로 독립이라고 한다. 이때, 먼저 도착한 사람이 5분 이상 기다리게 될 확률을 구하라.
40확률변수 $X$ 와 $Y$ 의 결합 확률밀도함수가 $$f(x,y)=\begin{cases}4,& 0\lt x\lt1,\ 1\lt y\lt2x\text{인 경우}\\ 0,& \text{그 외의 경우}\end{cases}$$ 라고 하자. 이때
  1. $x$ 에 관한 $Y$ 의 조건부 기댓값 $E(Y\mid x)$ 을 구하라.
  2. $y$ 에 관한 $X$ 의 조건부 기댓값 $E(X\mid y)$ 을 구하라.
  3. $x$ 에 관한 $Y$ 의 조건부 분산 $E[Y-E(Y\mid x)\mid x]^2$ 을 구하라.
41확률변수 $X$ 의 확률밀도함수가 $$f(x)=\begin{cases}1/18,& x=1,3\text{인 경우}\\ 16/18,& x=2\text{인 경우}\end{cases}$$ 로 주어졌을 때, $P(|X-E(X)|\ge\delta)=Var(X)/\delta^2$ 를 만족하는 $\delta$ 를 찾아라.
42$X\sim B(n,p)$ 일 때 $Y=n-X$ 의 분포를 구하라.
46$X\sim\text{POI}(\lambda)$ 일 때 $E(1+X)^2$ 을 계산하라.
48모든 눈이 나올 확률이 동일한 주사위를 던지는 시행을 고려하자.
  1. $6$ 의 눈이 나올 때까지 던진다면, 최소한 $5$ 번의 시행이 필요할 확률은 얼마인가?
  2. 주사위의 눈 $6$ 이 나올 확률이 $1/2$ 보다 크기 위해서는 몇 번의 시행이 필요한가?
49$7$ 게임으로 구성된 어느 시합(예를 들면 한국시리즈 야구시합)에서 두 팀 $A$ 와 $B$ 가 겨루게 되었다. 매 게임에서 무승부는 없으며, $A$ 팀이 이길 확률이 $p$ 라고 할 때
  1. $A$ 팀이 $x$ 번째 게임에서 시합에 우승할 확률을 구하라.
  2. 이 시합이 $7$ 번째 게임에서 끝날 확률을 구하라.
51$X\sim\text{HYP}(n,N,r)$ 일 때, $N\to\infty,\ r\to\infty,\ r/N\to p$ 이면 $$\lim_{\substack{N\to\infty,\ r\to\infty\\ r/N\to p}}\frac{\dbinom{r}{x}\dbinom{N-r}{n-x}}{\dbinom{N}{n}}=\binom{n}{x}p^x(1-p)^{n-x}$$ 가 성립함을 증명하라.
53$X\sim N(\mu,\sigma^2)$ 일 때, 다음의 기댓값들을 계산하라.
  1. $E(X^3)$
  2. $E[(X-\mu)^3]$
54$X\sim N(\mu,\sigma^2)$ 일 때,
  1. $Y=|X-\mu|$ 의 확률밀도함수를 구하라.
  2. $Y=\exp(X)$ 의 확률밀도함수를 구하라(이를 로그 정규확률밀도함수라고 한다).
55두 변수 $X$ 와 $Y$ 가 서로 독립인 $U(0,1)$ 확률변수라고 하자. 이때 $Z=X-Y$ 의 확률밀도함수를 구하라.
56$a\gt0,\ b\gt0$ 에서 $B(a,b)=\dfrac{\Gamma(a)\Gamma(b)}{\Gamma(a+b)}$ 임을 보여라.
57양수인 $\alpha_1,\alpha_2,\alpha_3$ 에 대해
  1. $0\lt y_1\lt1$ 일 때, $$\int_0^{1-y_1}y_2^{\alpha_2-1}(1-y_1-y_2)^{\alpha_3-1}\,dy_2=\frac{\Gamma(\alpha_2)\Gamma(\alpha_3)}{\Gamma(\alpha_2+\alpha_3)}(1-y_1)^{\alpha_2+\alpha_3-1}$$ 임을 보여라.
  2. 다음 함수가 확률밀도함수가 됨을 보여라. $$f(y_1,y_2)=\begin{cases}\dfrac{\Gamma(\alpha_1+\alpha_2+\alpha_3)}{\Gamma(\alpha_1)\Gamma(\alpha_2)\Gamma(\alpha_3)}\,y_1^{\alpha_1-1}y_2^{\alpha_2-1}(1-y_1-y_2)^{\alpha_3-1},& y_1\gt0,\ y_2\gt0,\ y_1+y_2\lt1\\[4pt]0,& \text{그 외의 경우}\end{cases}$$
59두 확률변수 $X$ 와 $Y$ 의 결합 확률밀도함수가 $$f_{X,Y}(x,y)=4e^{-2(x+y)},\qquad x\gt0,\ y\gt0$$ 으로 주어졌다.
  1. $Z=X+Y$ 의 확률밀도함수를 구하라. $Z$ 가 어떤 분포를 따르는지 서술하시오.
  2. $U=X/Y$ 와 $V=X$ 의 결합 확률밀도함수를 구하라.
  3. (2)로부터, $U$ 의 주변 확률밀도함수를 구하라.
61$X\sim\text{GEO}(p)$ 의 적률생성함수를 계산하라.
62확률변수들 $X_i\ (i=1,2,\cdots,k)$ 는 서로 독립이며 $\text{GEO}(p)$ 분포를 따른다고 하자. 이때 $\displaystyle\sum_{i=1}^k X_i$ 의 적률생성함수를 구하고 그의 분포를 알아보라.
63$2.6$ 절에 소개된 코시확률변수는 적률이 존재하지 않음을 보여라.
66확률변수 $X$ 의 적률생성함수가 $M_X(t)=\tfrac19 e^{t}+\tfrac13 e^{3t}+\tfrac59 e^{5t}$ 로 주어졌을 때,
  1. $P(X=3)$ 을 계산하라.
  2. $X$ 의 확률밀도함수를 구하라.
67결합 확률밀도함수가 $f_{X,Y}(x,y)=e^{-y}\ (0\lt x\lt y)$ 인 두 확률변수 $X$ 와 $Y$ 의 결합 적률생성함수를 구하라.
